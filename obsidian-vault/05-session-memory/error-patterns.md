# Banco de Erros Recorrentes — Memória da Bianca

> Atualizado automaticamente após cada sessão. A Bianca consulta este arquivo para não repetir sempre a mesma correção e para identificar quando é hora de dedicar uma aula inteira a um ponto.

---

## Como Interpretar

- **Frequência:** quantas vezes o erro apareceu no total de sessões
- **Última ocorrência:** data da última vez que o erro foi identificado
- **Abordado diretamente:** se já foi tema de explicação dedicada
- **Status:** Ativo (ainda ocorre) / Melhorando / Resolvido

## Regra de Escalada

Quando um erro aparece **3 vezes ou mais**: → Bianca dedica um momento específico na próxima aula para trabalhar aquele ponto → Marca como "Abordado" após a explicação → Monitora nas 2 sessões seguintes

Quando um erro **não aparece por 3 sessões consecutivas**: → Move para "Erros Resolvidos" → Registra como conquista do aluno
